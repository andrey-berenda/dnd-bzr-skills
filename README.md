# dnd-bzr-skills

Claude-скиллы для консалтинга по охране труда в Сербии (BZR). Язык работы скиллов — сербский (латиница).

| Скилл | Назначение |
|---|---|
| [`rs-bzr-akt-review`](rs-bzr-akt-review/SKILL.md) | Ревью документов: akt o proceni rizika, elaborat/plan preventivnih mera/prijava gradilišta, stručni nalaz по осмотру и испытаниям, обучение, evidencije, медосмотры, dozvola za rad, работа на высоте |
| [`rs-bzr-akt-izrada`](rs-bzr-akt-izrada/SKILL.md) | Составление черновиков тех же документов (опирается на чек-листы ревью) |

## Нормативная база
Снимок на **2026-10-10**: ZBZR 35/2023, pravilnik о процене ризика 76/2024, pravilnik о pregledu opreme 76/2024, Uredba о gradilištima и др.; срок применения ряда подзаконных актов — **1.1.2027**. Каждая норма помечена уровнем уверенности ([T] текст прочитан, [S] вторичный источник, [?] не подтверждено) — см. `rs-bzr-akt-review/references/baseline-propisi.md`.

Не покрыто: пожарная безопасность, снижение рисков катастроф, отходы, химикаты.

## Установка
Скачать `.skill` из Releases (или упаковать папку скилла в zip с расширением `.skill`) и добавить в Claude. Скрипты (`extract_text.py`, `lint_akt.py`) — только стандартная библиотека Python 3; для PDF нужен `pdftotext`.

## Статус
Черновик. Не протестирован на реальных актах. Не заменяет лицензированного специалиста и не является юридическим заключением.
